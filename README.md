# Online Shoppers Purchasing Intention — Classification

An end-to-end machine learning project that trains multiple classification models
to predict whether an e-commerce browsing session ends in a purchase, and serves
them through an interactive Streamlit web app.

- **GitHub repository:** https://github.com/vipinkumar29/online-shopping-intention-ml
- **Live Streamlit app:** _<to be added after deployment>_

## Problem statement

Predict the target `Revenue` (purchase vs no purchase) for an online shopping
session — a binary classification problem.

## Planned models

- Logistic Regression
- Decision Tree
- k-Nearest Neighbors
- Naive Bayes (Gaussian)
- Random Forest
